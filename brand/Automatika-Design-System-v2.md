# Automatika™ Design System v2

## Design Goal
Create a premium, trustworthy, intelligent, calm, and professional experience.

## Visual Personality
### Primary Feel
- Clean
- Spacious
- Editorial
- Sophisticated

### Secondary Feel
- Human
- Warm
- Modern

## Color Strategy

### Base Layer (70%)
- White
- Cream
- Very Light Gray

### Structure Layer (20%)
- Light Gray
- Soft Cream
- Muted Neutral

### Attention Layer (10%)
- Accent Lime: `#C7FD11`

### Color Formula
80% Neutral / 15% Dark Contrast / 5% Accent

## Typography

### Headings
- Font: Poppins
- Weights: 600, 700, 800

### Body
- Font: Inter or Roboto
- Weights: 400, 500

### Size Hierarchy
| Element | Size |
|----------|----------|
| Hero | 48–64px |
| Major Section | 32–40px |
| Card Heading | 22–28px |
| Body | 16–18px |
| Small Text | 13–14px |

## Spacing

### Section Spacing
48–96px

### Block Spacing
32–48px

### Card Padding
24–32px

## Layout System

### Reading Pattern
1. Image
2. Headline
3. Description
4. CTA
5. Divider
6. Next Story

### Page Structure
1. Hero
2. Problem
3. Solution
4. Benefits
5. Proof
6. CTA
7. Footer

## Card Design

### Radius
16–20px

### Border
1px soft gray

### Shadow
```css
box-shadow: 0 10px 25px rgba(0,0,0,.06);
```

## CTA Design

### Primary Button
Background: `#C7FD11`
Text: `#111827`

### Secondary Button
Background: `#FFFFFF`
Border: `#E5E7EB`
Text: `#111827`

## Dashboard Rules

### Top
- Large metrics
- Short explanation

### Middle
- Cards
- Charts
- Insights

### Bottom
- Activity logs
- History
- Audit trails

## Motion Rules

### Allowed
- Fade In
- Hover Lift
- Soft Transitions

Duration: 300ms–500ms

### Avoid
- Bounce
- Shake
- Flash
- Spinning Elements

## Master Formula

- White + Cream Backgrounds
- Charcoal Typography
- Lime Highlights
- Editorial Headlines
- Large Whitespace
- Rounded Cards
- Subtle Shadows
- Premium Photography
- One Primary CTA Per Screen
