DevLabs vs a plain AI tool

Every agent in DevLabs is a real AI coding tool (Claude Code, Codex, Gemini and others), running the same program you would run yourself in a terminal. DevLabs doesn't replace the tool. It runs many copies of it, connects them, and adds the things a single terminal window doesn't have.

What you wantPlain tool in a terminalThe same tool inside DevLabs
Several helpers at onceOne window per session. You switch between them and keep track yourself.Up to 15 agents per office floor, as many floors as you like, up to 200 windows. Each card shows whether that agent is working, waiting or idle.
Someone to split up the workYou write every prompt and decide who does what.Ramon, the manager agent, reads your request, writes clear tasks, gives each to the best agent (or hires one) and checks it's done.
Agents that talk to each otherSessions can't see each other. You copy and paste between them.Agents send each other messages. A message waits in line and arrives when the receiving agent finishes its current step.
Knowing what's in progressScroll back through the terminal.A task board (to do, doing, blocked, done), a live activity feed, and the office itself: busy agents sit at their desks, free ones go to the Kapihan.
Getting finished files backFind the file on disk yourself.Deliveries: a preview, Approve or Request changes, Save a copy. Each delivery is a snapshot, so later edits don't change what you approved.
Questions the AI has for youThe terminal waits until you notice.Questions land in Ramon's human tab, and a desktop notification can ping you.
Memory between sessionsEach new session starts fresh unless you set up memory yourself.Every agent keeps its own notes. Optional MemPalace search lets all agents look things up by meaning, and the knowledge base lets them read your own documents.
Picking up after a restartYou find the session id and resume it by hand.DevLabs records each agent's session. Restart & Continue or restore team brings agents back with the same name, memory and conversation (for the tools that support resuming).
Keeping spending under controlWatch the tool's own usage page.Per-agent and team token budgets, a circuit breaker that steers, then slows, then stops a runaway agent, and the ATM showing cost per agent and per day.
Stopping safelyClose the window or press Ctrl+C.stop after this step, block tools, pause for the whole team, and closing time: everyone saves their work and notes before the app quits.
Work that starts by itselfWrite your own cron jobs or scripts.Schedules, Discord, Slack and webhook triggers hand work to Ramon automatically.
Using your other appsFind, install and configure each MCP server yourself.Settings → Connections: paste a key, switch it on. Keys are stored encrypted, and web connectors reach the vendor through DevLabs so the agent never sees the key.
Extra skillsFind and copy skill folders yourself.Security-audit, skill-inspector and the ponytail skills come built in, and the DevLabs Skills Library installs more after checking every file.
Reviewing changes before you keep themSet up git branches or worktrees yourself.Tick Git isolation when hiring: the agent works on its own copy of the project.
Mixing AI companiesA different tool, a different window, a different way of working for each.Claude, Codex, Gemini, Grok, Qwen and more on one floor, all getting the same identity, inbox and controls.
Sharing a team you builtShare your prompts and settings files by hand.export floor… saves the whole team as one file. Others import it in one click, with no paths, keys or memory inside.
No terminal skills neededYou type commands and read raw output.Plain-language buttons, an office you can watch, and voice: dictate with Free Flow or talk to Ramon out loud.
When a plain terminal is enough. For one quick question or a small single change, the AI tool on its own is simpler and starts faster. DevLabs earns its keep when you have several jobs at once, long-running work, work that should start by itself, or people who don't want to use a terminal.
What DevLabs adds on top, honestly. It is another app running on your computer and uses some memory and processor time. It chooses some command-line options for each tool (for example the auto-mode option), so a few of your usual flags are set from Settings instead. Connectors work with Claude Code agents only today. Every agent costs AI usage, so ten agents can cost about ten times as much as one.

How to read this manual

  • Settings → General means: click the gear at the top right of the window, then the General tab on the left.
  • Ramon's Command Center opens when you click Ramon (his card is first in the bottom strip). Its tabs are the icons along the top; hover one to see its name.
  • Most settings apply to agents you start after the change. Agents already running keep what they started with. To apply a change to a running agent, use Restart & Continue.

Your team

Ramon, the manager on

What it is

The one agent who is always there. He wears a red name tag and sits in the BOSS office on Floor 1. He reads your requests, plans the work, hands it to agents, hires new ones when nobody fits, and tells you when it's done.

Why use it

You talk to one person instead of managing every agent. Ramon also checks who's already in the building before hiring, so you don't pay for duplicates.

How to set it up
  1. Ramon is created on first start. In setup step 2 (Ramon's engine) pick the AI tool he uses.
  2. To change his model later: click Ramon → floor tab → the manager model picker.
Good to know
  • There's one Ramon for all your windows. He can hand work to agents in any window.
  • Ramon can also hire short-term helpers for one job. They show in the workers tab and leave by themselves when finished.

Hiring agents on

What it is

Adding an AI helper with its own name, look, project folder, AI tool, model and standing job.

How to do it
  1. Click add agent (end of the bottom strip, or add at the top of the office).
  2. Give it a name and pick a character and colour.
  3. Choose its project folder: the folder it may work in.
  4. Pick the engine (AI tool) and model.
  5. Write its goal in plain words, for example "Writes friendly product descriptions for our online shop".
  6. Optional: tick Git isolation (own worktree) (see Git isolation), or paste a session id to resume an earlier conversation.
  7. Press spawn. Nothing starts until you do.
Faster ways
  • Role templates: pick a ready-made Technical or Non-technical role and everything is filled in.
  • Agent gallery: pre-configured hires you can spawn in one click.
  • import hire…: load one agent from a file someone shared.
  • generate one with AI…: copy the given text into any AI chat, describe the agent, save the answer as a file and import it.
Good to know
  • Agents stay until you fire them (the red ✕). A stopped agent keeps its name, memory and workspace.
  • To bring back a fired agent: Command Center → Archived → show closed agents → return to floor, then restore team.

Company builder setup

What it is

Describe your business in a sentence and get a whole planned team (roles, goals, tools) to review.

How to use it
  1. add agent → company builder.
  2. Describe your business, for example "a small online plant shop that sells on Facebook".
  3. Review the proposed team. Change or remove anyone.
  4. Confirm to hire. Nobody is hired before you confirm.
Good to know
  • Your company description is sent to Groq or Claude to plan the team.

Floor files: whole teams in one file on

What it is

A .floor.json file holding a whole team: each agent's name, job, goal, look, engine, model and token budget.

How to share your team
  1. add agent → export floor…
  2. Give it a name and press save file…
How to use someone's team
  1. add agent → import floor… (or open an atmtlabs://floor?src=… link).
  2. Read the review screen: it lists every agent and the apps they need.
  3. Press hire all, review one by one, or cancel.
Good to know
  • A floor file never includes your folders, keys, memory or conversations.
  • It can't run commands on its own: DevLabs builds every command from your own settings. It can still give an agent a goal you didn't expect, so read the review screen.

Project floors off

What it is

A completely separate team for a different project folder, with its own agents, history and memory.

How to turn it on
  1. Settings → General → Project floors → new project floor…
  2. Pick the project's folder and press create floor & restart.
Good to know
  • Your current team is kept. Go back to it from the start screen.

Many windows: your building on

What it is

Each DevLabs window is its own team (say, research, coding and marketing). Together they make your building.

How to use it
  1. App menu → New Floor, or Ctrl+Shift+N (Windows, Linux) / Cmd+Shift+N (Mac).
  2. Hire the team for that window.
Good to know
  • Up to 200 windows. Agents can message agents in other windows, and Ramon sees them all.
  • Closing a window stops its agents (the app asks first). Their history is kept.
  • Tip: put the team in the name, like F2 Marketing - Liza.

Getting work done

Dispatch through Ramon on

What it is

The main way to give work: write what you want once, and Ramon turns it into tasks for the right agents.

How to use it
  1. Click Ramon → floor tab → dispatch via Ramon.
  2. Describe the result in plain words, and say the file type you want back ("as an HTML file", "as a Word document").
  3. Press dispatch, then watch the office and the tasks tab.
Good to know
  • The floor tab can also hand out GitHub issues: pick issues and Ramon assigns them.

What it is

Finished files handed back to you for review: web pages, documents, PDFs, pictures.

How to use it

  2. Open Ramon → deliveries (a number shows how many are new).

Agent abilities

AI engines & models setup

What it is

The AI tool each agent runs on. DevLabs doesn't sell AI: you install and sign in to the tools you want, and each one bills your own account.

How to set it up
  1. Open Settings → Prerequisites. It checks what's installed and shows READY, MISSING or NOT SET UP.
  2. Install the tools you'll use (not all of them), or press ask Ramon to set up everything. That only fills in his dispatch box; nothing runs until you press dispatch.
  3. Sign in to each tool once, the way its own instructions say.
  4. Pick default models in Settings → Agents & Models. New Claude agents start on Opus 5.5 and new Codex agents on GPT-6 Sol unless you change it.
Good to know
  • Max turns per run (Agents & Models → Advanced) limits how long one run can go. Blank means unlimited.
  • See What each AI tool gets for which features each tool supports.

Connectors setup

What it is

Links that let agents work inside other apps: Pancake POS, Webcake Landing, Fireflies.ai meeting notes, Obsidian, Discord, GitHub, databases, email & calendar, web search.

How to turn one on
  1. Settings → Connections. Each connector has a How to set up link with the exact steps.
  2. Paste the key the other app gives you and press Save. It's stored encrypted and never shown again.
  3. Switch the connector On.
  4. Start a new agent. Running agents keep the connectors they started with.
Special cases
  • Obsidian needs no key: press choose folder, pick your vault, switch it on. Agents never overwrite or delete a note.
  • Discord needs your own bot: create it at discord.com/developers/applications, copy the bot token, turn on Message Content Intent, and invite it with View Channels, Send Messages and Read Message History.
Good to know
  • Connectors change real data in those apps. Use keys with only the access you need.
  • Claude Code agents only, for now.

Long-term memory (MemPalace) setup

What it is

Every agent always keeps plain notes. MemPalace adds search by meaning across all agents' notes, so one agent can find what another learned last week.

How to turn it on
  1. Settings → Prerequisites → Memory layer: install it.
  2. Open the 🧠 memory panel and press Turn on.
  3. Pick a search language: Fast (English only, about 90 MB) or Multilingual (all languages, about 300 MB).
  4. Make sure Settings → Memory & Knowledge → Cross-session recall is on.
Good to know
  • Search it yourself in the memory panel or Ramon's memory / graph tabs.
  • Everything stays on your computer.

Knowledge base off

What it is

Your own documents, images and PDFs, indexed so agents can look things up in them when they need to.

How to turn it on
  1. Settings → Memory & Knowledge → Knowledge Graph.
  2. Press add files… and choose your documents. The count shows how many are indexed.
  3. Start a new agent, or Restart & Continue an existing one.

Personality, 3D look & prompt library on

What it is

Personality describes who an agent is and how it talks. 3D look changes its character. The prompt library holds ready-made instructions for its role.

How to use it
  1. Click an agent → edit → personality. It's written as its own section in the agent's instruction file (CLAUDE.md, AGENTS.md or GEMINI.md) in its project folder; the rest of the file is left alone. It applies from the next session.
  2. edit → 3D look → change hair, clothes, colours → Save avatar.
  3. In the queue, press prompts to insert a saved instruction.

Automation

Schedules off

What it is

A request that repeats on a timetable, for example "every Monday at 9am, summarise last week's sales".

How to turn it on
  1. Ramon → triggers tab → Schedules.
  2. Write the request, set when it runs, and save.
Good to know
  • Schedules only run while DevLabs is open. See Keep working while away.

Discord trigger setup

What it is

@-mention your bot in a Discord channel and Ramon picks up the request; the answer is posted back in the channel.

How to turn it on
  1. Set up the Discord connector first and keep it on.
  2. In Discord: Settings → Advanced → turn on Developer Mode, then right-click a channel → Copy Channel ID.
  3. Ramon → triggers → Discord: paste the channel IDs and switch it on.
  4. Optional: add other people's user IDs under Who can start work.
Good to know
  • Only you (the bot's owner) can start work unless you add people, because these requests run without asking. Messages from anyone else are ignored.

Slack setup

What it is

A Slack message starts a request. Ramon spins up a short-lived worker that replies in the thread, then closes.

How to turn it on
  1. Settings → Connections → Slack → Show Slack connect steps and follow them.
  2. Paste the Signing secret and Bot token (channel id is optional) and press start.
  3. Copy the Request URL it shows into Slack's Event Subscriptions.
Good to know
  • Proactive posting (DevLabs posting first) is off by default.
  • Running Slack workers show in Ramon's workers tab, where you can stop them.

Webhooks off

What it is

A web address another tool can send work to (a form, a store, an automation service).

How to turn it on
  1. Settings → Connections → Webhook triggers → add webhook.
  2. Copy its URL and Secret into the other tool. Show webhook API format shows what to send.
  3. Switch it on.
Good to know
  • A webhook that's on is a public address anyone holding its secret can post to. New ones start off. Use rotate if a secret leaks.

Scheduled auto-compact off

What it is

Agents tidy their working memory on a schedule (every 2 hours by default), so long-running agents don't run out of room.

How to turn it on
  1. Settings → General → Maintenance → Scheduled auto-compact.
  2. Change the interval in Ramon's triggers tab.

Keep working while away off

What it is

Settings that keep schedules and terminals running on time while you step away.

How to turn it on
  1. Settings → General → Keep Mac awake while agents run (also offered in setup as Keep working while away). Uses more battery; best plugged in.
  2. Open at login (setup step 4) relaunches DevLabs after a reboot so schedules resume.
  3. Your system's own sleep setting: setup step 4 has an open Power settings / open Battery settings button.
Good to know
  • If your computer fully sleeps, timers pause and catch up when you're back. Nothing is lost; it may just run late.

Closing time on

What it is

The safe way to quit. Ramon tells every agent to save its work and write down where it stopped; the app quits when everyone has confirmed.

How to use it
  1. Quit DevLabs while agents are running.
  2. In the dialog, choose closing time. A progress view shows who has packed up.
  3. Cancel any time if you change your mind.

Control & safety

Auto mode vs ask-first on

What it is

Autonomous: agents act without asking. Ask-first: agents pause and ask before running commands or changing files.

How to change it
  1. Settings → Autonomy & Budgets → Autonomy.
  2. Pick autonomous or ask-first. It applies to agents started after the change.
  3. You can override it for one agent in the Add Agent dialog.
Good to know
  • Auto mode keeps each tool's own safety sandbox where it has one (Codex runs in workspace-write mode, not the full bypass).
  • Use ask-first on important projects you can't easily undo.

Git isolation off

What it is

The agent works on its own copy of the project (a git worktree), so you review its changes before they reach your main copy.

How to turn it on
  1. When hiring: tick Git isolation (own worktree) in the workspace section.
  2. The project folder must be a git repository.
Good to know
  • Not available when you resume an earlier session.

Token budgets off

What it is

A ceiling on how much AI work the team, or one agent, may use. An agent that hits its limit stops.

How to turn it on
  1. Team: Settings → Autonomy & Budgets → floor token budget (total tokens across the floor).
  2. One agent: Ramon → floor tab → set its token limit.
Good to know
  • See what's been used in the ATM and the floor tab's usage bars.

Circuit breaker on

What it is

A safety brake for runaway agents. When an agent burns tokens too fast, repeats the same tool over and over, or hits a storm of errors, the breaker first steers it, then constrains it, then stops it. Its card shows looping.

How to tune it
  1. Settings → Autonomy & Budgets → Circuit breaker.
  2. Set token velocity (tokens per minute), repeated-tool limit and error-storm limit.
  3. Hard stop: choose steer first (recommended) or kill on trip.

Pause everyone on

What it is

Stops messages being delivered to all agents until you turn it back on.

How to use it
  1. Click the auto button at the top of Ramon's Command Center. It changes to paused.
  2. Click again to resume.

Restart & Continue / restore team on

What it is

Brings a stopped or stuck agent back with the same identity, memory and (where the tool supports it) the same conversation.

How to use it
  1. One agent: Ramon → floor tab → restart & continue next to it.
  2. Everyone after reopening the app: restore team in the agent strip.
Good to know
  • Also fixes a garbled terminal: it redraws without losing the conversation.

Desktop notifications off

What it is

A system notification when an agent finishes, needs your input, or a terminal needs reviving.

How to turn it on
  1. Settings → General → Notifications → Desktop notifications.
  2. Allow notifications if your system asks the first time.

Voice

Free Flow dictation setup

What it is

Speak instead of typing. Your words are turned into text in the queue box so you can check them before sending.

How to turn it on
  1. Get a Groq API key at console.groq.com.
  2. Settings → Voice → Free Flow: paste the Groq API key and pick a model (fast or accurate).
  3. Dictate: click the mic above Send (click again to finish), or hold Option (⌥) while viewing a terminal and release to finish.
Good to know
  • Your recording is sent to Groq to be transcribed. Your system asks for microphone permission the first time.

Talk to Ramon setup

What it is

A live voice conversation with Ramon: you speak, he answers out loud and can act on what you say.

How to turn it on
  1. Get an OpenAI API key (this is separate from any Claude subscription).
  2. Settings → Voice → OpenAI API key · voice → paste → Save. Choose your microphone and speaker there too.
  3. Press talk on Ramon's card. Press again to stop.
Good to know
  • Idle auto-disconnect (30 seconds to 10 minutes, or off) closes a silent session. A spending cap still stops a runaway session.
  • The key is encrypted on your computer; each session gets its own short-lived token.

Spoken replies setup

What it is

The first sentences of each agent reply are read out loud.

How to turn it on
  1. Press the gear at the top right of the office.
  2. Switch Voice replies on and paste an ElevenLabs key (elevenlabs.io → Profile → API keys).
  3. Pick a voice and speed and press Preview.
Good to know
  • Reply text is sent to ElevenLabs to make the audio.

  4. Delete an empty floor: view it, press − Delete floor N, confirm.
Good to know
  • Only empty floors can be deleted, and never Floor 1. Deleting a floor never deletes an agent or any work.

Decorating on

  1. Press the pencil (top right of the office).
  2. Click an object in the list, then click the floor to place it.
  3. Select an object to move it, rotate it ([ ]), nudge it (arrow keys), lift it (Page Up/Page Down) or remove it (Delete). Select a desk to choose who sits there.
  4. Press the ✓ when you're done. Reset restores the original layout.

App settings

Language & plain words on

  1. Settings → General → Language: English, 简体中文 or العربية.
  2. Explain things simply: agents brief you in plain language instead of technical shorthand.
  3. Arabic / RTL text in terminals: makes Arabic join and read right to left in terminals (a little slower). It follows your app language unless you change it here.

Updates on

What it is

DevLabs checks for a new version about 30 seconds after opening and every 6 hours, and downloads it in the background. It never restarts on its own.

How to use it
  1. The version number at the top left says when an update is ready. Click it to check now or to restart into the new version.
  2. Turn it off in Settings → General → Auto-update.
Good to know
  • On some Macs and the portable Windows version you get a download button instead.

Anonymous usage stats on

A handful of anonymous events (app opened, agent started, feature used). Never prompts, code, file paths or agent output. You choose in setup step 4; switch it off any time in Settings → General → Anonymous usage stats. The full list is in TELEMETRY.md.

Reset & backups on

Reset this floor
  1. Settings → General → reset floor.
  2. Choose back up ZIP & reset (recommended) or reset without backup.

This stops all agents and clears the team, conversations, tasks, board and shared memory. Your settings, schedules and project folders stay. RESTORE.txt inside the ZIP explains how to put everything back. The ZIP can contain private messages; keep it private.

Reset everything

Settings → General → DANGER ZONE → reset & start over erases every agent, all memory and all settings and returns you to setup. It can't be undone.

Moving the home folder on

  1. Settings → General → Home folder → change...
  2. Pick the new folder. Move existing data (recommended) copies everything and leaves the old folder as a backup; Start fresh begins empty.
  3. Press move & restart (or switch & restart).
