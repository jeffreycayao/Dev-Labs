Privacy Policy

Last updated October 21, 2026

This policy explains how jepoy.dev (Jeffrey Cayao, "we", "us") handles data for the open-source DevLabs desktop app ("the App") and this website (jepoy.dev).

1. The short version

  • There is no account and no sign-in. The App does not send us your email, name or computer details.
  • Your projects, files, prompts, agent output, memory and connector keys stay on your computer.
  • We do not sell personal data, use it for advertising, or use it to train AI models.

2. Your AI tools are separate services

The agents are AI tools you install and sign in to yourself (such as Claude Code, Codex, Gemini or Cursor). When an agent works, that tool sends your prompts and files to its own company, under that company's terms and privacy policy, not ours. The same applies to connectors such as Pancake POS and Webcake.

3. Optional anonymous usage stats

Official builds can send anonymous usage events (for example, "an agent was started") to PostHog Cloud (United States). Events carry a random install ID created on your computer, and no email, name, IP address, file names, prompts or output. Turn this off in Settings → General → Anonymous usage stats, or set the DO_NOT_TRACK environment variable. Builds you compile yourself send nothing. The full list of events is in TELEMETRY.md.

4. Updates

While auto-update is on, the App asks GitHub for the latest public release. GitHub sees that request under its own privacy policy.

5. This website

This website sets no cookies and runs no analytics or advertising scripts. Our host (Vercel) keeps short-lived request logs, such as IP address and page, for security and error diagnosis.

6. Your rights

Wherever you live, you can ask us what data we hold about you and ask us to correct or delete it. Philippine residents have the rights of a data subject under the Data Privacy Act of 2012 (RA 10173); EU, EEA and UK residents have their rights under the GDPR / UK GDPR.

7. Changes

We'll post changes on this page and update the date at the top.
